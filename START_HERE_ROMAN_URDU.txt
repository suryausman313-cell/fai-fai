============================================================

============================================================
STEP 3 — NEW RENDER BACKEND
============================================================

1. Render > New > Web Service.
2. New fai-fai-juice GitHub repository connect karo.
3. Service name: fai-fai-juice-backend
4. Root Directory:
   app/backend
5. Build Command:
   pip install -r requirements.txt
6. Start Command:
   uvicorn main:app --host 0.0.0.0 --port $PORT
7. Environment Variables:

   DATABASE_URL = NEW Fai Fai Neon connection string
   JWT_SECRET_KEY = koi lamba random secret
   KITCHEN_PIN = 1122
   ENVIRONMENT = prod

FIRST DEPLOYMENT PAR:
MGX_IGNORE_INIT_DATA variable abhi MAT lagana.
Isse Fai Fai starter categories, juice menu, extras aur settings new database me banengi.

8. Deploy karo aur Render Live hone do.
9. Render ka backend URL copy karo, example:
   https://fai-fai-juice-backend.onrender.com
10. Render variables me add karo:

   PYTHON_BACKEND_URL = apna Render backend URL
   FRONTEND_URL = Cloudflare URL baad me add hoga
   MGX_IGNORE_INIT_DATA = 1

11. Save/redeploy karo.

Backend test:
https://YOUR-BACKEND.onrender.com/api/v1/receipt-settings

JSON me Fai Fai Juice aur printer settings nazar aani chahiye.
